Variables in PHP

  • A variable is a temporary memory block that stores a value.
  • No strong declaration needed; PHP decides data type automatically.
  • Syntax: $variable_name = value;
  • Strings must be in double quotes; numbers need not.

Loops in PHP

A loop is a cyclic repetition of a process that executes a specific task. The condition is checked:

  • If the condition is true, the loop iterates.
  • The loop keeps iterating until the condition becomes false.
  • When false, the loop stops and control is sent outside the loop.

Types of Loops in PHP

  1. while loop
  2. do…while loop
  3. for loop
  4. foreach loop

While Loop Syntax

initialize the loop_variable;
while(condition) {
    // Code
    // Increment / Decrement the loop_variable
}

Do-While Loop Syntax

initialize the loop_variable;
do {
    // Code
    // Increment / Decrement the loop_variable
} while(condition);

For Loop Syntax

for(initialization; condition; increment/decrement) {
    // Code
}

Arrays

→ An array is a special variable.

→ An array can store multiple values in a single variable.

→ Three types of arrays:

  • Indexed array
  • Associative array
  • Multidimensional array

Indexed Array

→ Syntax for empty indexed array declaration:

$array_name = array();

→ Syntax to declare an indexed array with values:

$array_name = array(value1, value2, value3);

→ Every array element has a unique index: min index = 0 & max index = size – 1

→ Access an array element using: $array_name[index]

→ Get the size of the array using: count($array_name)

→ Display the whole array using: print_r($array_name)

→ Access all array elements in a loop:

for($index_var = 0; $index_var < count($array_name); $index_var++) {
    echo $array_name[$index_var];
}

Indexed Array Example

<?php
// Declare an indexed array with values
$cities = array("New Delhi", "Mumbai", "Chennai", "Kolkatta");

// Get the array size
echo("<br>Total Cities: " . count($cities));
echo("<br>");

// Display the whole array
print_r($cities);

// Access individual array elements
echo("<br>City at index 0: " . $cities[0]);
echo("<br>City at index 2: " . $cities[2]);

// Access all elements using a loop
echo("<ul>");
for($i = 0; $i < count($cities); $i++) {
    echo("<li>".$cities[$i]."</li>");
}
echo("</ul>");
?>

Functions

→ A function is a block of statements used to perform a specific task.

  • Two types of functions:
    • Pre-defined / Built-in functions (e.g., isset(), echo())
    • User-defined functions
  • User-defined functions allow code reusability and better organization.

Function Definition & Call Syntax

function FunctionName($arguments) {
    // code
}

FunctionName($arguments);

Notes:

  • Arguments passed in function call must match the function definition.
  • Use return $varname; to return a value.
  • Only a single value can be returned.
  • Catch the returned value in a variable.

include() & require()

include():

  • Used to include the data of one PHP file into another.
  • Helps in reusing classes, functions, and designs.
  • Syntax: include("Source_file.php");
  • Warning is produced on error, but script execution continues.

require():

  • Similar to include(), but stops script execution on error.
  • Syntax: require("Source_file.php");

Classes and Objects in PHP

Rules:

  • → class is a keyword.
  • → ClassName, property_name & member_function_name are identifiers.
  • → access_specifiers control security of members:
    • private → only inside class
    • protected → inside class + derived class
    • public → inside + outside class
  • → Access member from inside function: $this->member_name

Object Declaration Syntax:

$object_name = new ClassName();

Access members via object:

$object_name->member_name;
$object_name->member_function($args);

Example

<?php 
class Employee { 
    private $empid; 
    private $empname; 
    private $bsal; 
    private $itr; 
    private $hra; 
    private $gsal; 
    
    public function set_data($id, $nm, $bs) { 
        $this->empid = $id; 
        $this->empname = $nm; 
        $this->bsal = $bs; 
    } 
    
    public function calculate() { 
        $this->itr = $this->bsal * 30.0/100.0; 
        $this->hra = $this->bsal * 40.0/100.0; 
        $this->gsal = $this->bsal + $this->hra - $this->itr; 
    } 
    
    public function getItr() { return $this->itr; } 
    public function getHra() { return $this->hra; } 
    public function getGsal() { return $this->gsal; } 
} 
?>

The __construct function

→ Special function called automatically when an object is created.

  • Name fixed: __construct()
  • May / may not take arguments
  • Cannot return a value
  • Only one constructor allowed per class
  • Can pass arguments to set data while creating object

Inheritance in PHP

→ Inheritance is creating a new class and deriving properties from a previously created class.

Benefits:

  • Reusability of code
  • Reduces code size, effort, time, and complexity

Types of Inheritance:

  1. Single Level
  2. Multi-Level
  3. Hierarchical

Single Level Inheritance

class SuperClass { } 
class SubClass extends SuperClass { }

Notes:

  • Private members of SuperClass cannot be accessed in SubClass
  • Protected members accessible in SubClass but not outside
  • Public members accessible in SubClass

Multi-Level Inheritance

class SuperClass { } 
class IntermediateSuperClass extends SuperClass { } 
class SubClass extends IntermediateSuperClass { }

Hierarchical Inheritance

class SuperClass { } 
class SubClass1 extends SuperClass { } 
class SubClass2 extends SuperClass { }

State Management

  • → By default, data of a page is not sharable across pages.
  • → State management helps share data across pages without forms.
  • → Technologies: Query String, Sessions, Cookies

Query String

  • Transports limited string data from source page to target page
  • Type & quantity: Strings up to 4kb
  • Storage: Client Browser's address bar
  • Security: Insecure
  • Scope: Available till target page runs
  • Syntax (single): TargetPageURL?key=value
  • Syntax (multiple): TargetPageURL?key1=value1&key2=value2
  • Retrieve in target page: $var = $_GET["key"];

Sessions

  • → PHP Sessions are used to store and pass information from one page to another temporarily.
  • → Sessions are widely used for sign in and shopping carts.
  • → Session is browser-specific; every browser gets a unique session id.
  • → Properties of Sessions:
    • Type & Quantity: Any data type and any size
    • Storage Location: Server's temporary memory
    • Security: Secure
    • Scope: Accessible throughout the website
    • Life: Available only while the session is alive
  • → Session destruction cases:
    • User initiated (logout)
    • Browser session ends

Sessions Syntax

  • Start session at the top of every PHP file: session_start();
  • Create/assign session data: $_SESSION["session_key"] = value;
  • Retrieve session data: $var = $_SESSION["session_key"];
  • Destroy session: 
    // remove all session variables
session_unset();
// destroy the session
session_destroy();

Example: session1.php

<?php
session_start();
?>

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Session 1</title>

        <input type="text" name="txtname" placeholder="John Doe">
        <input type="email" name="txtemail" placeholder="name@example.com">
        <button type="submit" name="btnsub">Create Session</button>

    <?php

Cookies

  • → Cookie is a global data store for your web application.
  • → Cookies are often used to identify a user.
  • → A cookie is a small file stored on the client's computer by the server.
  • → Typically used for "remember me" or "stay signed in" functionality.
  • → Properties of Cookies:
    • Type & Quantity: Strings only, limited size (1KB-4KB)
    • Storage Location: Client browser cache
    • Security: Insecure
    • Scope: Accessible throughout the website
    • Life: Available until cookie expires
  • → Cookie destruction:
    • Using browser settings
    • Cookie timeout

Cookie Syntax

  • Create cookie: setcookie("cookie_name", "cookie_value", timeout);
  • Timeout example:
    • 5 minutes: time() + 5*60
    • 1 hour: time() + 1*60*60
    • 15 days: time() + 15*24*60*60
  • Retrieve cookie: $_COOKIE["cookie_name"]

Example: cookie1.php

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Cookie 1</title>
</head>

        <input type="email" name="txtemail" placeholder="name@example.com">
        <button type="submit" name="btnsub">Create Cookie</button>
    </form>

    <?php
    if(isset($_POST["btnsub"])) {
        $name = $_POST["txtname"];
        $email = $_POST["txtemail"];
        setcookie("cookie_name", $name, time() + 3*60);

Interfaces

  • → Interface is a class-like entity.
  • → We define interfaces like classes using the interface keyword.
  • → Interfaces cannot have properties; only public member methods can be declared.
  • → Interfaces cannot be instantiated.
  • → A class inherits an interface using implements and must define all interface methods.

Interface Syntax

interface InterfaceName {
    public function function_name($arguments);
}

class ClassName implements InterfaceName {
    public function function_name($arguments) {
        // method body
    }
}

Example: IFace1

<?php
interface IFace1 {
    public function fun1();
}

class MyClass implements IFace1 {
    public function fun1() {
        echo "<br/>fun1() runs.";
    }
}

$obj = new MyClass();
$obj->fun1();
?>

Abstract Classes & Polymorphism

Abstract Member Functions

  • → Abstract member functions are special functions declared in the parent class only.
  • → They cannot be defined in the parent class.
  • → Must be prefixed with abstract keyword.
  • → Can be public or protected.
  • → Syntax: abstract access_specifier function member_function_name($args);
  • → All derived classes must define these functions with the same signature.

Abstract Class

  • → Abstract class is a parent class containing at least one abstract member function.
  • → Declared with abstract keyword.
  • → Cannot create an object of abstract class directly.
  • → Can contain properties and regular member functions.

Example: Employee Abstract Class

<?php
abstract class Employee {
    public $empid;
    public $empname;
    public $workinghours;
    public $workingdays;

    public function setEmpData($empid, $empname, $workinghours, $workingdays) {
        $this->empid = $empid;
        $this->empname = $empname;
        $this->workinghours = $workinghours;
        $this->workingdays = $workingdays;
    }

    abstract public function calculateSalary();
}
?>

Derived Classes

<?php
require_once("Employee.php");

class PermanentEmployee extends Employee {
    public function calculateSalary() {
        return $this->workinghours * 100 * $this->workingdays + 10000;
    }
}

class TemporaryEmployee extends Employee {
    public function calculateSalary() {
        return $this->workinghours * 50 * $this->workingdays;
    }
}
?>

Polymorphism

  • → Poly – many, Morph – forms.
  • → Allows objects of different classes to have same signature methods.
  • → Implemented via:
    • Abstract Classes
    • Interfaces

Polymorphism using Abstract Class

<?php
abstract class Person {
    abstract public function greet();
}

class English extends Person {
    public function greet() { return "Hello!"; }
}

class German extends Person {
    public function greet() { return "Hallo!"; }
}

class French extends Person {
    public function greet() { return "Bonjour!"; }
}

// usage
$person_eng = new English();
echo "<br/>English Person says: ".$person_eng->greet();
?>

PHP File Handling

File Operations Overview

  • Open a file (fopen())
  • Read from a file (fread())
  • Write to a file (fwrite())
  • Append data to a file
  • Close a file (fclose())
  • Delete a file (unlink())

Open a File (fopen())

Syntax:

$file_pointer = fopen("filename.txt", "mode");

File Opening Modes in PHP

Mode Description
r Read only. Starts at the beginning of the file
r+ Read/Write. Starts at the beginning of the file
w Write only. Opens and clears the contents of file; or creates a new file if it doesn't exist
w+ Read/Write. Opens and clears the contents of file; or creates a new file if it doesn't exist
a Append. Opens and writes to the end of the file or creates a new file if it doesn't exist
a+ Read/Append. Preserves file content by writing to the end of the file

Close a File (fclose())

fclose($file_pointer);

Read from Text File (fread())

<?php
$fp = fopen("data.txt", "r");
$content = fread($fp, filesize("data.txt"));
echo $content;
fclose($fp);
?>

Write to Text File (fwrite())

<?php
$fp = fopen("data.txt", "w");
$data = "Hello World!";
fwrite($fp, $data);
fclose($fp);
echo "Data written successfully";
?>

Append Data to Text File

<?php
$fp = fopen("data.txt", "a");
$data = "\nNew line added";
fwrite($fp, $data);
fclose($fp);
echo "Data appended successfully";
?>

Deleting File from Website

<?php
if(unlink("data.txt")) {
    echo "File deleted successfully";
} else {
    echo "File could not be deleted";
}
?>

Error Handling in PHP

PHP provides several ways to handle errors:

Die() Statement

Working with APIs

PHP can be used to interact with REST APIs using cURL or file_get_contents().

GET Request using file_get_contents()

<?php
$url = "https://api.example.com/data";
$response = file_get_contents($url);
$data = json_decode($response, true);
print_r($data);
?>

POST Request using cURL

<?php
$url = "https://api.example.com/data";
$data = array('key1' => 'value1', 'key2' => 'value2');

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, array('Content-Type: application/json'));

$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
print_r($result);
?>
