# Computer Oriented Numerical Methods - Practical Work

A comprehensive collection of C++ implementations for various numerical methods commonly used in computer science and engineering applications.

## 📚 Overview

This repository contains practical implementations of 25 fundamental numerical methods as part of the Computer Oriented Numerical Methods coursework. Each program is designed to demonstrate core concepts in numerical analysis and computational mathematics.

## 🌐 Live Demo

Visit the interactive website to explore all programs with syntax highlighting and one-click compilation:
[View Live Site](https://computer-oriented-numerical-methods.vercel.app/)

## 📋 Program List

### Number System Conversions

1. **Binary to Decimal and Vice Versa** - Convert between binary and decimal number systems
2. **Floating Point Addition** - Implement floating point addition
3. **Floating Point Subtraction** - Implement floating point subtraction

### Root Finding Methods

4. **Bisection Method** - Find roots using interval halving technique
5. **Regula Falsi (False Position) Method** - Linear interpolation method for root finding
6. **Secant Method** - Iterative root-finding using secant lines
7. **Newton Raphson Method** - Fast convergence root finding using derivatives
8. **Birge Vietta Method** - Polynomial root finding and evaluation

### System of Linear Equations

9. **Gauss Elimination Method** - Direct method for solving linear systems
10. **Gauss Jordan Method** - Matrix reduction to reduced row echelon form
11. **Gauss Siedel Method** - Iterative method for solving linear systems

### Interpolation Methods

12. **Newton's Backward Difference Interpolation** - Interpolation using backward differences
13. **Newton's Forward Difference Interpolation** - Interpolation using forward differences
14. **Lagrangian Interpolation** - Polynomial interpolation using Lagrange basis
15. **Newton's Divided Difference Interpolation** - Interpolation using divided differences

### Numerical Integration

16. **Trapezoidal Method (Tabulated)** - Numerical integration using trapezoidal rule for tabulated data
17. **Trapezoidal Method (Functional)** - Numerical integration using trapezoidal rule for functions
18. **Simpson's 1/3 Method** - Numerical integration using Simpson's rule
19. **Simpson's 3/8 Method** - Numerical integration using Simpson's 3/8 rule

### Differential Equations

20. **Runge Kutta 2nd Order Method** - Second-order method for solving ODEs
21. **Runge Kutta 4th Order Method** - Fourth-order method for solving ODEs
22. **Euler's Method** - Basic method for solving first-order ODEs
23. **Modified Euler's Method** - Improved Euler method for better accuracy
24. **Taylor Series Method** - Solving ODEs using Taylor series expansion

### Special Functions

25. **Chebyshev Polynomials** - Implementation of Chebyshev polynomial approximation

## 🚀 Getting Started

### Prerequisites

- C++ compiler (GCC, Clang, or MSVC)
- Web browser (for viewing the interactive site)

### Using the Web Interface

1. Open `index.html` in your web browser
2. Browse through the list of programs
3. Click on any program to view its source code with syntax highlighting
4. Use the "Run Code" button to copy code and open it in an online compiler
